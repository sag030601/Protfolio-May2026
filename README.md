# Sagar Singh — Premium Portfolio

Modern, deployment-ready developer portfolio built with React, Vite, Tailwind CSS, Framer Motion, and React Icons.

## Quick Start

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

Deploy the `dist/` folder to Vercel, Netlify, or GitHub Pages.

## Customize

| Content | File |
|---------|------|
| Skills | `src/data/skills.js` |
| Projects | `src/data/projects.js` |
| Contact & achievements | `src/data/contact.js` |
| Resume | `public/resume.html` |
| Profile image | `src/assets/profile.svg` |

## Features

- Dark/light mode with localStorage persistence
- Sticky navbar with active section highlighting
- Scroll progress indicator & back-to-top button
- Framer Motion animations (fade-up, stagger, counters)
- Category-filtered skills with level indicators
- Data-driven projects section
- Contact form with validation
- Code-split lazy-loaded sections
- SEO meta tags
